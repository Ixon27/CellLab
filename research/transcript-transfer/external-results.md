# 세포 종류별 예측이 좋아지는 이유는 기증자 수일까, 세포 수일까?

**결론:** Kang의 시료를 더 많이 합치면 독립 실험의 반응 유전자 목록을 더 잘 찾는 경우가 있었다. 하지만 세포 수를 적게 고정한 대조에서는 기증자를 늘려도 같은 향상이 나타나지 않았다. ‘기증자 4명이면 충분하다’는 결론은 이 데이터로 뒷받침되지 않는다.

### 외부 평가

Kang의 미사용 donor를 정답으로 보는 기존 분석과 다르다. 독립 실험의 [Parse 10M PBMC](https://www.parsebiosciences.com/datasets/10-million-human-pbmcs-in-a-single-experiment)에서 Allen Institute가 12명 자료로 계산해 공개한 [세포 아형별 IFN-beta 대 PBS 상·하향 500 유전자 목록](https://apps.allenimmunology.org/aifi/resources/parse-10m-cytokines/downloads/)을 정답 목록으로 사용했다. [자료 인용·기여자](https://apps.allenimmunology.org/aifi/resources/parse-10m-cytokines/cite/), CC BY-NC 4.0. 원시 1천만 세포를 재분석한 것이 아니다. Kang의 6시간 처리와 Parse의 24시간 처리는 다르므로 여기는 **다른 조건으로의 전달성**이지 동일 조건 반복 검증이 아니다. 공개 목록은 추정된 순위이지 생물학적 정답이 아니다.

`external.py`는 Kang에서만 계산한 세포 종류별 상위 100개 유전자 중 Parse의 같은 방향 목록에 포함되는 비율을 측정한다. 비교군은 Kang의 나머지 다섯 세포 종류 반응의 동일 가중 평균이다. Parse의 더 세밀한 주석은 사전에 정한 1~2개 하위 유형과 대응시켜 각각 채점한 뒤 6개 큰 유형에 동일 가중을 준다. 모든 원천 donor 조합을 사용하며 외부 결과를 이용해 유전자를 선택하지 않는다. 위·아래 방향은 따로 보고한다.

| Kang donor 수 | 상향: 유형별 / 다른 유형 평균 | 하향: 유형별 / 다른 유형 평균 |
|---:|---:|---:|
| 1 | 27.0% / 32.6% | 7.4% / 7.9% |
| 2 | 32.9% / 32.5% | 9.3% / 9.2% |
| 4 | 36.1% / 32.3% | 11.7% / 10.5% |
| 8 | 37.4% / 32.3% | 14.7% / 11.3% |

### 가장 중요한 반증 검사

위 표에서 donor를 늘리면 관측 세포도 늘어난다. `budget.py`는 **탐색적 사후 대조**로 64회 무작위 비복원 표집을 시행한다. 같은 세포 종류·같은 처리군에서는 총 세포 수를 고정하고 1/2/4/8명의 donor에 균등 배분한다. B 24개, CD14 120개, CD4 128개, CD8 8개, CD16 32개, NK 16개/조건을 사용했다(가장 작은 donor 시료에 맞춘 저세포수 시나리오). 각 조건에서 계수를 먼저 합쳐 log CPM을 계산한다. 상향 유전자 유형별 적중률은 donor 1명 26.3%, 8명 25.4%; 비교군은 34.6%, 34.4%. 하향 유전자에서는 이득이 두 경우 모두 1%p 미만이었다. 숫자는 중복된 donor와 64회 계산 표집의 평균이지 독립 코호트 64개의 결과가 아니다.

같은 ‘합산 후 로그’ 추정량으로 **donor당** 위의 세포 수를 고정하여 총 세포 수가 donor 수에 비례하도록 한 추가 대조도 수행했다. 8명에서 유형별 상향 적중률 26.6%, 다른 유형 평균 31.6%였다. 따라서 세포 수 증가만으로 원래 전체자료의 우위가 돌아온다고 말할 수도 없다. 이 결과가 지지하는 것은 donor 수의 보편적 임계값이 아니라 **분석 방식과 관측 깊이에 따른 결론의 민감성**이다.

**해석 제한:** 세포수 고정 분석의 합산 후 로그와 전체 세포 분석의 donor별 로그 후 평균은 다른 추정량이다. 두 표의 차이를 오직 세포 수의 인과 효과로 해석하지 않는다. 비교군은 여러 유형의 정보를 빌리므로 표본이 적을 때 유리하다. 같은 추정량을 사용한 donor 수 × 세포 깊이 요인 실험을 여러 자극·독립 데이터에서 반복하고, 단순 평균과 유형별 모델 사이의 부분 풀링까지 비교해야 일반화 가능한 방법 논문이 된다. 현재는 단일 자극의 타당성 확인이다.

재현 (`run.py`와 같은 환경):

```sh
CACHE="$HOME/tmp/celllab-transcript-transfer"
python external.py "$CACHE" results
python budget.py "$CACHE" results
python budget.py "$CACHE" results --per-donor
```
