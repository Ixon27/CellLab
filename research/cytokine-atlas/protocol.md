# Frozen analysis plan: independent cross-species stress test

Before scoring: source = [Cui et al. mouse lymph node cytokine atlas](https://doi.org/10.1038/s41586-023-06816-9), Supplementary Table 3 using the [authors’ human symbol mapping](https://www.immune-dictionary.org/download). Target = independent human Parse 10M PBMC Allen signatures, as in `../transcript-transfer/external.py`. This is a new source study, not a new human target relative to the Kang pilot. It does not test donor number, nor is mouse–human transfer a substitute for human–human replication.

- Evaluate all exactly matching ligand names after Greek letter spelling and hyphen normalization, excluding IFN-beta (discovery). No family-level or receptor substitutions. B, CD4 T, CD8 T, NK (same two human subtypes per type as pilot), CD14/CD16 monocytes averaged into one target for mouse monocytes. Require all five sources present for a ligand and both directions available for all human subtypes. Equal weight across directions, lineages and then ligands. Log all exclusions.
- Mouse source is a selected list of genes, not a full effect matrix: do not call unlisted loci measured zeros. For scoring only, no listed effect contributes zero. Drop human symbols receiving multiple distinct mouse genes in the input. Predict from own signed log2FC, equal average of the other four, and fixed half own + half other. Sort in the requested direction; no zero-score padding, ties broken by symbol. For matched budget per ligand/type/direction use k=min(100, positive directional candidates from each method); eligibility k>=10. Report k and fraction eligible, avoid generalizing to weak responses. Sensitivity: fixed budget of 100 slots on all eligible-by-ligand tasks, unfilled slots count as misses. Hit = in the same direction human published top list, averaged across mapped subtypes. These are signature retrieval scores, not biological sensitivity.
- Primary contrast: half-mix minus own. Also report other minus own and half minus other. Report ligand-level differences, sign counts, leave-one-ligand-out range and up/down separately. Ligands reuse studies, donors, pathways; do not treat cells/ligands as independent cohorts. No universal superiority claim. Target panels or weights will not be optimized.
