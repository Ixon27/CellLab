# Source-only reliability-weighted pooling (locked before Wood donor results)

Question: can a simple noise estimate decide how much of another lineage's response to borrow? Source tensor is paired treated-minus-control log response by donor, lineage and gene; same genes and held-out labels as the fixed benchmark. For each lineage and donor subtract the equal-weight mean of the other included lineages. For each donor subset of size k≥2, let d be the gene vector of mean deviations. Set w=max(0,1−sum_g Var_donor(deviation_g)/(k × sum_g d_g²)); if the denominator is zero set w=0. Source-only score = other-type mean + w*d. One scalar per lineage and subset, not tuned to target. If k=1 use the already-fixed 1:1 blend; not counted as evidence for adaptation. Deviations include compositional changes and technical noise; this is a shrinkage heuristic, not a causal or novel estimator.

Primary: target Up/Down gene list precision at 100, same genes and cell types for own-only, others-only, half blend and adaptive. Compare within ligand, same donors. Evaluate Wood IL-2 and IL-4 separately (new source and ligands; Parse target reused); report directions and k separately. For a decision to advance the rule require the adaptive method to beat **each** fixed method on each ligand, direction-averaged at all available donors; descriptive, not a significance test. Smaller subsets give robustness estimates, not independent cohorts. Do not tune failure away. Kang IFN-beta discovery doubles as an implementation calibration, not an additional independent replication. If complete comparable per-donor vectors are unavailable, do not replace with per-cell pseudo-donors.
